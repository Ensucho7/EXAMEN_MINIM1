Flota de Drones

API REST para gestionar drones, pilotos, mantenimiento y planes de vuelo. Toda la documentacion interactiva esta disponible en Swagger.

Abrir Swagger UI

Endpoints principales

  • POST /dsaApp/flota/drones - anadir un dron
  • POST /dsaApp/flota/pilotos - anadir un piloto
  • GET /dsaApp/flota/drones - listar drones por horas de vuelo
  • GET /dsaApp/flota/pilotos - listar pilotos por horas de vuelo
  • POST /dsaApp/flota/drones/{id}/mantenimiento - guardar un dron en mantenimiento
  • POST /dsaApp/flota/mantenimiento/reparar - reparar el dron mas cercano a la puerta
  • POST /dsaApp/flota/planes - crear un plan de vuelo
  • GET /dsaApp/flota/pilotos/{id}/planes - planes de un piloto
  • GET /dsaApp/flota/drones/{id}/planes - planes de un dron
